# AutoCredit

AutoCredit 是一个 Windows 桌面小工具，用于每天在 Trae、Qoder、Qoder CN、WorkBuddy 上静默签到并领取积分。另有一个默认隐藏的豆包实验功能，可在设置中开启开发者模式后使用。

> 本项目仅供个人使用，与 Trae、Qoder、WorkBuddy 及其所属公司没有任何关联，也未获得其官方认可或授权。

## 功能

- 全局主开关，开启后只签到已启用的程序
- 每个程序独立开关、独立签到时间
- 开机自启动，开机时静默在托盘运行；手动双击图标会正常打开主界面
- 启动、休眠唤醒、解锁后自动补签
- 同一天只签到一次，失败后按间隔重试
- 签到前在屏幕右下角弹出 10 秒倒计时窗口，可点击 × 取消；全屏应用运行时自动跳过
- 系统托盘常驻，关闭窗口后继续在后台运行
- 自动检查 GitHub Release 更新，也可从托盘菜单手动检查
- 本地日志查看与导出
- 扁平化的苹果风格界面

## 支持的程序

| 程序 | 登录方式 |
| --- | --- |
| Trae CN | 读取本机 Trae 登录态 |
| Qoder | 在设置中填写个人访问令牌（PAT） |
| Qoder CN | 在设置中填写个人访问令牌（PAT） |
| WorkBuddy | 读取本机 WorkBuddy 登录态 |
| 豆包（实验） | 启动本机豆包客户端并通过调试端口模拟点击；默认隐藏，需在设置中开启开发者模式 |

豆包签到属于实验功能，依赖本机已登录的豆包桌面端，可能随客户端更新失效。

## 开发与打包

需要 Windows 10/11 与 Node.js 20 及以上版本。

```bash
npm install
npm run dev        # 开发模式
npm run typecheck  # 类型检查
npm run dist       # 打包 Windows 安装包，产物在 release/
```

## 更新与卸载

- 安装版启动后会自动检查 GitHub Releases，发现新版本时在后台下载并提示重启安装；也可以从托盘菜单「检查更新…」手动检查
- 设置 → 关于中可开启「接收 dev 版本」，开启后会同时检查预发布版本
- 安装包为标准 NSIS 安装程序，卸载可通过 Windows「设置 → 应用」或安装目录下的 `Uninstall AutoCredit.exe`
- 卸载默认保留本机配置与加密令牌，重新安装后可继续使用

## 安全与隐私

- Qoder / Qoder CN 的个人访问令牌使用 Electron `safeStorage`（Windows DPAPI）加密后保存在本地，不会上传到任何第三方服务
- 日志与配置仅保存在本机用户数据目录，日志中不记录令牌
- 具体说明与漏洞报告方式见 [SECURITY.md](SECURITY.md)
